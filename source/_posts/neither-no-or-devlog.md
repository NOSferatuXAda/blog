> 时间范围：2026-11-17 ～ 2026-11-22
> 设备：树莓派（代码主副本）+ Windows 笔记本（文档主副本 / 代码镜像）
> 目标：用 Godot 从零做一个 3D 项目，并在双机之间安全地并行推进代码与文档

这不是教程，是一份按时间整理的工作日志。保留关键决策和结论，省略重复的等待与调试。

## 阶段 1｜环境与文档启动（11-17）

**做了什么**

1. 在树莓派上装 Godot 4.7.2：apt 源只有 Godot 3，改从 GitHub releases 拿 arm64 官方包，软链到 ~/.local/bin/godot。
2. 建 GDD 设计文档 v0.1，把需求落到纸面。

## 阶段 2｜双线并行（11-18）

**分工确立**

- 树莓派：代码主副本
- Windows：文档主副本 + 代码镜像
- 约定：代码只在树莓派改，Windows 只改文档

**做了什么**

1. 我在树莓派这边做手感打磨——移动加减速、后坐与摆动、镜头踢动、按住连发、hitstop、命中标记、准星修复。
2. Windows 那边把 GDD 从 v0.2 推到 v0.4，完成第一轮 27 题问答。

## 阶段 3｜代码冲刺 v2 → v11（11-19）

单日改动最密的一天，代码版本从 v2 一路到 v11。

1. v2-v6：手感反馈、靶子随机刷新、资源骨架、像素渲染管线重构（SubViewport 640×360 渲染 + 1080p UI 叠加）。
2. 氛围地基：print/glitch shader + 电波音。
3. Windows 镜像同步：v7 单文件重构、v8 灰盒关卡、v9 室内曝光、v10 门与碰撞、v11 光烘焙。
4. 冲突记录（19:52）：Windows 那边用整文件恢复覆盖了我这边 19:48 追加的改动，导致解析失败，之后我这边重做了一遍。

## 阶段 4｜demo 同步与优化（11-21）

1. 收到外部 demo 包，独立解包审查 → 优化 → 测试后合入。
2. 优化项：END 冻结、精英冲撞、限幅器复用、BFS 缓存、审片图隔离、integer 缩放。
3. 自检：79/79 冒烟 + 五项专项探针全绿，main.gd SHA256 校验，合入前 tar 备份。

## 阶段 5｜设定与美术重置（11-19 晚 ～ 11-22）

1. 用户要求重定设定、重做美术，旧文档的「已定」不再自动有效。
2. 建独立工作稿目录：18 份文档 + 概念板 + 风格帧 + 模型 v03→v13 + 验证脚本。
3. 自检里程碑：完整 144/144、战斗 41/41、配色 132/132。

## 经验与坑

1. 双线并行的覆盖冲突：两处改同一文件，一方的整文件恢复会冲掉另一方改动。改前先划清职责边界，冲突后要有重做预案。
2. 单文件重构趁早：代码从 v1 单文件一路涨到 v11，越往后拆越贵。
3. 自检自动化：冒烟 + 专项探针 + SHA256 校验，交付前先自证，而不是等报错。
4. 大合入前备份：每次同步外部代码前先 tar，出了问题能回退。
